# AGENTS.md 对话导入器

一个无需构建的 Chrome Manifest V3 扩展，用于把本地 `AGENTS.md` 规范导入网页大模型的聊天输入框。

首版支持：

- `https://chat.deepseek.com/*`
- `https://www.doubao.com/*`

扩展只负责把内容写入输入框，**不会自动点击发送**。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页面。
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录，也就是包含 `manifest.json` 的目录。
5. 建议把扩展固定到浏览器工具栏。

扩展更新后，在扩展管理页面点击本扩展的“重新加载”，并刷新已经打开的 DeepSeek 或豆包页面。

## 使用

1. 打开 DeepSeek 或豆包聊天页面。
2. 点击工具栏中的扩展图标。
3. 在“全局规范”中选择通用的 `AGENTS.md`。
4. 如有需要，再为当前网站选择一个专属 Markdown 文件。
5. 点击“导入到当前输入框”，检查内容后手动发送。

也可以按 `Alt + Shift + I` 直接导入。浏览器若没有采用默认快捷键，可在以下页面检查或修改：

- Chrome：`chrome://extensions/shortcuts`
- Edge：`edge://extensions/shortcuts`

扩展弹窗会显示当前实际生效的快捷键。点击“更改快捷键”可直接打开上述浏览器设置页；浏览器不允许扩展自行改写快捷键，因此需要在该页面中完成修改。

当全局文件和网站专属文件同时存在时，扩展会先放入全局规范，再放入网站规范。同一个输入框再次导入时，旧的规范块会被最新文件内容替换，不会重复叠加。

## 本地文件权限

受浏览器安全机制限制，扩展不能在未经授权的情况下直接读取固定磁盘路径。首次使用必须手动选择文件。

扩展会把浏览器提供的文件句柄保存在扩展自己的 IndexedDB 中，但不会长期保存文件正文。每次导入都会重新读取磁盘上的最新内容。如果浏览器重启或安全策略导致权限失效，请打开扩展弹窗并点击“重新授权”。

如果文件被移动或删除，请重新选择文件。

## 隐私说明

- 文件内容只在本机读取。
- 扩展自身不会把内容上传到任何服务器。
- 只有在你主动触发导入时，内容才会写入当前 DeepSeek 或豆包输入框。
- 扩展不会自动发送对话。
- 扩展只申请两个目标网站、活动标签页、脚本注入和本地扩展状态所需权限。

请注意：当你手动点击网页的发送按钮后，输入框中的内容将按照目标网站自身的隐私政策发送给相应服务商。

## 项目结构

```text
assets/icons/ 扩展清单、工具栏和弹窗使用的图标资源
background/   后台导入流程与快捷键处理
content/      网页输入框探测、写入与提示条
lib/          文件句柄存储和规范块合并逻辑
popup/        扩展弹窗界面
tests/        无第三方依赖的核心逻辑测试
manifest.json Chrome Manifest V3 配置
```

## 开发检查

项目没有构建步骤和第三方依赖。可使用 Node.js 运行核心文本合并测试：

```powershell
node tests/instruction-block.test.js
```

网站输入框结构可能随站点升级而变化。相关适配选择器集中在 `content/content.js` 的 `SITE_SELECTORS` 中，添加新站点时还需同步更新 `manifest.json` 的访问范围和弹窗中的站点名称映射。
